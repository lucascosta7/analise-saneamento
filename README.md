# Projeto de Análise de Saneamento com Python e Pandas

📌 Este projeto utiliza dados públicos de saneamento para realizar análises com Python e Pandas.

## 🔍 Objetivo
Analisar a situação de investimento e cobertura de água e esgoto nos municípios brasileiros.

## 🛠️ Tecnologias usadas
- Python
- Pandas
- Jupyter Notebook

## 📊 Análises realizadas
- Estados que mais investem em água e esgoto
- Percentual de acesso a água por município
- Cobertura de esgoto por estado
- Municípios com zero investimento

## 📎 Dataset
O dataset utilizado foi `saneamento.csv`, com dados de populações, investimentos e cobertura de água/esgoto.
